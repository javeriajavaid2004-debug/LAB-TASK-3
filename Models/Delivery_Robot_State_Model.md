# Delivery Robot State Model
## States
### 1. IDLE
The robot is waiting for a delivery request.
### 2. NAVIGATING
The robot is moving toward the destination.
### 3. AVOIDING_OBSTACLE
The robot is avoiding an obstacle.
### 4. DELIVERING
The robot is delivering the package.
### 5. RETURNING
The robot is returning to the warehouse.
## Events / Conditions
- Delivery Request Received
- Destination Reached
- Delivery Successful
- Warehouse Reached
- Obstacle Detected
- Obstacle Avoided
- Critical Battery
